# Design Review In-depth Guide

> Detailed reference for Phase 7. Provides scoring criteria, scenario focus points, and a checklist of common issues.

---

## Detailed Scoring Criteria

### 1. Philosophy Alignment

| Score | Criteria |
|------|----------|
| 9-10 | Design perfectly embodies the core spirit of the chosen philosophy, with every detail having a philosophical basis. |
| 7-8 | Overall direction is correct, core features are in place, but individual details deviate. |
| 5-6 | Intention is visible, but execution mixes in elements from other styles, lacking purity. |
| 3-4 | Only superficial imitation, without understanding the philosophical core. |
| 1-2 | Fundamentally unrelated to the chosen philosophy. |

**Review Focus Points**:
- Are the signature techniques of the designer/agency used?
- Do the colors, fonts, and layout conform to the philosophical system?
- Are there any "contradictory" elements? (e.g., choosing Kenya Hara but filling it with content)

### 2. Visual Hierarchy

| Score | Criteria |
|------|----------|
| 9-10 | User's gaze naturally flows according to the designer's intent, with zero friction in information acquisition. |
| 7-8 | Primary and secondary relationships are clear, with occasional 1-2 instances of ambiguous hierarchy. |
| 5-6 | Titles and body text are distinguishable, but intermediate levels are chaotic. |
| 3-4 | Information is flat, with no clear visual entry points. |
| 1-2 | Chaotic, users don't know where to look first. |

**Review Focus Points**:
- Is the font size contrast between titles and body text sufficient? (at least 2.5x)
- Do color/weight/size establish 3-4 clear levels of hierarchy?
- Is whitespace guiding the eye?
- "Squint test": Squint your eyes, is the hierarchy still clear?

### 3. Craft Quality

| Score | Criteria |
|------|----------|
| 9-10 | Pixel-perfect, with no flaws in alignment, spacing, or color. |
| 7-8 | Overall refined, with 1-2 minor alignment/spacing issues. |
| 5-6 | Basically aligned, but spacing is inconsistent, and color usage is not systematic enough. |
| 3-4 | Obvious alignment errors, chaotic spacing, too many colors. |
| 1-2 | Rough, looks like a draft. |

**Review Focus Points**:
- Is a consistent spacing system used (e.g., 8pt grid)?
- Is the spacing consistent for similar elements?
- Is the number of colors controlled? (usually no more than 3-4)
- Is the font family consistent? (usually no more than 2)
- Is edge alignment precise?

### 4. Functionality

| Score | Criteria |
|------|----------|
| 9-10 | Every design element serves its purpose, with zero redundancy. |
| 7-8 | Function-oriented, with a few decorative elements that could be removed. |
| 5-6 | Basically usable, but with obvious decorative elements that distract. |
| 3-4 | Form over function, users have to work hard to find information. |
| 1-2 | Completely overwhelmed by decoration, losing the ability to convey information. |

**Review Focus Points**:
- If any element were removed, would the design worsen? (If not, it should be removed)
- Are CTAs/key information in the most prominent positions?
- Are there elements added "just because they look good"?
- Does information density match the medium? (PPTs should not be too dense, PDFs can be denser)

### 5. Originality

| Score | Criteria |
|------|----------|
| 9-10 | Refreshing, finding unique expression within the chosen philosophical framework. |
| 7-8 | Has its own ideas, not just simple template application. |
| 5-6 | Mediocre, looks like a template. |
| 3-4 | Heavily uses clichés (e.g., gradient spheres representing AI). |
| 1-2 | Completely template-based or a patchwork of assets. |

**Review Focus Points**:
- Are common clichés avoided? (See "Common Design Issues Checklist" below)
- Is there personal expression while adhering to the design philosophy?
- Are there "unexpected but reasonable" design decisions?

## Scenario-Specific Review Focus

The review focus varies for different output types:

| Scenario | Most Important Dimension | Secondary Importance | Can Be Relaxed |
|----------|--------------------------|----------------------|---------------------------------------|
| WeChat Official Account Cover/Illustrations | Originality, Visual Hierarchy | Philosophy Alignment | Functionality (single image without interaction) |
| Infographic | Functionality, Visual Hierarchy | Craft Quality | Originality (accuracy prioritized) |
| PPT/Keynote | Visual Hierarchy, Functionality | Craft Quality | Originality (clarity prioritized) |
| PDF/Whitepaper | Craft Quality, Functionality | Visual Hierarchy | Originality (professionalism prioritized) |
| Landing Page/Official Website | Functionality, Visual Hierarchy | Originality | — (Comprehensive requirements) |
| App UI | Functionality, Craft Quality | Visual Hierarchy | Philosophy Alignment (usability prioritized) |
| Xiaohongshu (Little Red Book) Illustrations | Originality, Visual Hierarchy | Philosophy Alignment | Craft Quality (atmosphere prioritized) |

## Top 10 Common Design Issues

### 1. AI Tech Clichés
**Issue**: Gradient spheres, digital rain, blue circuit boards, robot faces
**Why it's an issue**: Users are already visually fatigued by these and cannot distinguish you from others.
**Fix**: Replace literal symbols with abstract metaphors (e.g., use a "dialogue" metaphor instead of a chat bubble icon).

### 2. Insufficient Font Size Hierarchy
**Issue**: Title and body text difference is too small (<2.5x)
**Why it's an issue**: Users cannot quickly locate key information.
**Fix**: Titles should be at least 3 times the size of body text (e.g., body text 16px → title 48-64px).

### 3. Too Many Colors
**Issue**: Using more than 5 colors, without primary/secondary distinction.
**Why it's an issue**: Visual clutter, weak brand identity.
**Fix**: Limit to 1 primary color + 1 secondary color + 1 accent color + grayscale.

### 4. Inconsistent Spacing
**Issue**: Arbitrary spacing between elements, no system.
**Why it's an issue**: Looks unprofessional, chaotic visual rhythm.
**Fix**: Establish an 8pt grid system (use only 8/16/24/32/48/64px for spacing).

### 5. Insufficient Whitespace
**Issue**: All space is filled with content.
**Why it's an issue**: Information overload leads to reading fatigue and actually reduces information transfer efficiency.
**Fix**: Whitespace should occupy at least 40% of the total area (60%+ for minimalist styles).

### 6. Too Many Fonts
**Issue**: Using more than 3 fonts.
**Why it's an issue**: Visual noise, weakens sense of unity.
**Fix**: Max 2 fonts (1 for titles + 1 for body text), use font weight and size to create variation.

### 7. Inconsistent Alignment
**Issue**: Some left-aligned, some centered, some right-aligned.
**Why it's an issue**: Destroys visual order.
**Fix**: Choose one alignment method (left-alignment recommended) and apply it globally.

### 8. Decoration Over Content
**Issue**: Background patterns/gradients/shadows overshadow the main content.
**Why it's an issue**: Prioritizing the wrong thing; users are there for information, not decoration.
**Fix**: "If this decoration were removed, would the design worsen?" If not, remove it.

### 9. Overuse of Cyber Neon
**Issue**: Dark blue background (#0D1117) + neon glow effects.
**Why it's an issue**: Default aesthetic no-go zone (baseline taste for this skill), and has become one of the biggest clichés – users can override based on their own brand.
**Fix**: Choose a more distinctive color scheme (refer to the color systems of 20 styles).

### 10. Mismatched Information Density and Medium
**Issue**: A full page of text in a PPT / 10 elements crammed into a cover image.
**Why it's an issue**: Different mediums have different optimal information densities.
**Fix**:
- PPT: 1 core idea per slide
- Cover image: 1 visual focal point
- Infographic: Layered presentation
- PDF: Can be denser, but requires clear navigation
