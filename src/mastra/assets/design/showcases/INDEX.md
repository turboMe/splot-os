## Usage Instructions

### Referencing during Phase 3 Recommendation
After recommending a design direction, you can display the pre-made screenshots for the corresponding scenario:
```
“This is what a WeChat Official Account cover looks like in the Pentagram style → [Display cover/cover-pentagram.png]”
“The Takram style for a PPT data page feels like this → [Display ppt/ppt-takram.png]”
```

### Scenario Matching Priority
1.  Exact match for user's required scenario → Directly display the corresponding scenario
2.  No exact match but similar type → Display the closest scenario (e.g., "Product Official Website" → Display SaaS Landing Page)
3.  No match at all → Skip pre-made examples and proceed directly to Phase 3.5 live generation

### Horizontal Comparison Display
The 3 styles for the same scenario are suitable for side-by-side display to help users compare visually:
-   “Here's the same WeChat Official Account cover, implemented in 3 different styles”
-   Display order: Pentagram (rational restraint) → Build (luxurious minimalism) → Takram (soft warmth)
